The Ebb Lifecycle Format defines how to describe a software lifecycle event, identify the versions it applies to, and carry evidence for the claim. Its specification version is independent of the Ebb implementation and package version.

- [Read the 1.0 working draft](https://velella.sh/ebb/spec/1.0/)
- [Specification changelog](https://velella.sh/ebb/spec/changelog/)
