## Short description

Evidence-backed lifecycle data for packages, runtimes, images and developer tools.

## Project description

Ebb helps developers and scanners check when software is deprecated, reaches end of support, or reaches end of life. Its TypeScript library and command-line tool read lifecycle rules that link to vendor announcements, official release schedules, or package registry notices. Ebb publishes signed data releases separately from the software so consumers can verify the snapshot they use. [Trust and verification](https://velella.sh/ebb/trust/)
