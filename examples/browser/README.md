# Ebb in the Browser

This example shows how to run Ebb entirely client-side in the browser.

## Features

- **Zero Node Dependencies:** Evaluates packages offline in the browser without backend server calls.
- **Works in Modern Browsers:** Compatible with Chromium, Firefox, WebKit, Safari, and Mobile browsers.
- **Fast:** Sub-millisecond evaluation in pure JavaScript.

## Running Locally

To serve this demo locally:

```bash
# Build the project
npm run build

# Start a simple static web server
npx serve examples/browser
```

Then open `http://localhost:3000` in your browser.
